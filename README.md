Meu trabalho é desenvolvido sob a marca **`rochwxs`**, seguindo uma abordagem visual minimalista e funcional: **monocromática, tipografia forte, hierarquia clara e interfaces sem elementos desnecessários**.

## Filosofia de design

> **Se não precisa estar ali, não está.**

A identidade visual da `rochwxs` segue uma abordagem **editorial e minimalista**.

* Preto e branco
* Tipografia como elemento principal
* Hierarquia visual clara
* Sem gradientes
* Sem sombras desnecessárias
* Bordas discretas
* Animações funcionais
* Interfaces objetivas

O objetivo não é fazer uma interface chamar atenção por si só, mas fazer o **produto ser o centro da experiência**.
