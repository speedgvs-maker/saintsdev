## Sobre

Desenvolvedor focado em **frontend** e aplicações **fullstack com Next.js**. Trabalho sob a marca `rochwxs`, com uma identidade visual própria: editorial, monocromática, sem cor, sem gradiente, sem sombra — tipografia forte e interface que não grita.

Uso IA como ferramenta funcional dentro dos meus produtos — geração de estrutura, automação, chat — nunca como decoração.
